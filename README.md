EcoCart E-Commerce Sales Analysis
An end-to-end Excel data analysis project built on raw e-commerce sales data for a fictional online store, EcoCart. The project covers data cleaning, pivot table analysis, and business insights, culminating in an executive summary.
Project Overview
• Tool used: Microsoft Excel
• Dataset: E-commerce sales records (product, category, revenue, quantity, payment method, sales channel, customer type, location, date)
• Total revenue analyzed: ₦4,546,400 across 150 transactions
Key Insights
• Fashion is the top-performing category (₦2,183,500), led by Sneakers, the single highest-revenue and highest-quantity product.
• Stationery is the weakest category, with Gel Pen Pack the lowest-revenue product.
• Returning customers generate more revenue (₦2,681,300) than new customers (₦1,865,100).
• Abuja is the top-performing city (₦1,209,000); Port Harcourt the weakest (₦735,900).
• Marketplace is the strongest sales channel; Website underperforms despite similar transaction volume to other channels.
• Cash is the most frequently used payment method.
• April was the peak revenue month (₦1,527,400); May was the lowest (₦808,700).
Recommendations
1. Expand Fashion/Sneakers inventory and consider bundling with Accessories.
2. Reassess Stationery’s place in the catalog given weak returns.
3. Audit the Website channel’s checkout experience and marketing spend.
4. Build retention-focused offers to convert more new customers into repeat buyers.
5. Investigate what drove April’s spike to replicate it in slower months.
6. Run targeted promotions in underperforming cities (Port Harcourt, Ibadan).
